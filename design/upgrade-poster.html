为什么不用 ThemeOverlay
minSdk 是 19， drawable 里引用 ?attr 要 API 21 才稳定解析 —— 4.4 盒子上会把强调色解析成透明。
所以全部走代码着色：ColorStateList / StateListDrawable / 自定义 shader。
